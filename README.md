# 🇩🇪 Deutsch

## 📖 Projektbeschreibung

UniBrief ist eine KI-gestützte Anwendung, die Studierende bei der Organisation und Bearbeitung universitärer Projekte unterstützt.

Die Anwendung analysiert Aufgabenstellungen im PDF-Format, extrahiert Anforderungen mithilfe von Large Language Models (LLMs) und erstellt strukturierte Checklisten.

Zusätzlich können Studierende ihre Abgaben überprüfen lassen, um fehlende oder unklare Anforderungen frühzeitig zu erkennen.

## ✨ Hauptfunktionen

- **Benutzerverwaltung:** Registrierung und Anmeldung mit JWT-Authentifizierung und Refresh Tokens.
- **Projektverwaltung:** Erstellung und Organisation universitärer Projekte.
- **PDF-Upload:** Hochladen und Verwalten von Aufgabenstellungen.
- **KI-Analyse:** Automatische Extraktion von Anforderungen aus PDF-Dokumenten.
- **Checklisten:** Erstellung und Bearbeitung interaktiver Aufgabenlisten.
- **Abgabeprüfung:** Vergleich eingereichter Dokumente mit den extrahierten Anforderungen.
- **Feedback-Berichte:** Übersicht über erfüllte, fehlende und unklare Anforderungen.
- **Mehrsprachigkeit:** Unterstützung verschiedener Sprachen in der Benutzeroberfläche.

## 🔄 Funktionsweise

1. Benutzer registrieren sich oder melden sich an.
2. Ein neues Universitätsprojekt wird erstellt.
3. Die Aufgabenstellung wird als PDF hochgeladen.
4. Die KI extrahiert die Anforderungen.
5. Aus den Anforderungen wird eine Checkliste generiert.
6. Studierende laden ihre Abgabe zur Überprüfung hoch.
7. UniBrief erstellt einen Bericht mit den Ergebnissen.

## 🎯 Projektziel

Das Ziel von UniBrief ist es, Studierenden die Analyse komplexer Aufgabenstellungen zu erleichtern, den Arbeitsaufwand zu reduzieren und die Qualität ihrer Abgaben zu verbessern.

# 🇬🇧 English

## 📖 Project Description

UniBrief is an AI-powered application designed to help university students organize and manage their academic projects.

The application analyzes assignment briefs in PDF format, extracts requirements using Large Language Models (LLMs), and generates structured checklists.

Students can also validate their submissions against the extracted requirements to identify missing or unclear elements before final submission.

## ✨ Key Features

- **User Authentication:** Secure registration and login using JWT authentication and refresh tokens.
- **Project Management:** Create and organize university projects.
- **PDF Upload:** Upload and manage assignment documents.
- **AI Requirements Extraction:** Automatically extract structured requirements from PDF files.
- **Interactive Checklists:** Generate checklists and track progress.
- **Submission Validation:** Compare submitted documents with project requirements.
- **Submission Reports:** Identify fulfilled, missing, and unclear requirements.
- **Multilingual Support:** User interface localization.

## 🛠️ Technology Stack

**Frontend**
- Flutter
- Dart

**Backend**
- Python
- FastAPI
- REST API
- JWT Authentication

**Database**
- PostgreSQL
- SQLAlchemy

**Artificial Intelligence**
- Large Language Models (LLMs)
- AI-powered document analysis

**Cloud & Deployment**
- Render – Backend hosting
- Cloudflare Workers – Web hosting
- Cloudflare R2 – File storage
- GitHub – Version control

## 🔄 Application Workflow

1. Register or log in.
2. Create a university project.
3. Upload an assignment PDF.
4. Extract requirements using AI.
5. Generate and manage a checklist.
6. Upload a submission for validation.
7. Review the submission report.

## 🎯 Project Goal

UniBrief aims to simplify the analysis of academic assignments, reduce manual effort, and help students improve the completeness and quality of their submissions.
